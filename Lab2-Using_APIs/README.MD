# Collecting Job Data Using APIs

## Overview

This project demonstrates how to collect job data from a public Jobs API and store the results in an Excel spreadsheet. The focus is on analyzing job postings for different technologies and locations.

## Features

- Access job listings through a public API
- Count job postings for specific technologies (e.g., Python, Java, C++)
- Count job postings for specific locations (e.g., Los Angeles, New York)
- Save the results in Excel files for easy analysis

## Purpose

The main goal of this project is to practice working with APIs, extract relevant job market data, and organize it for analysis using Python. It helps understand trends in technology demand across various regions.

## Dataset

The data comes from a JSON dataset derived from job postings on Naukri.com, provided with the lab for educational purposes.
