# Scraping Programming Languages and Salaries

## Overview

This project demonstrates how to scrape data from a publicly available HTML table containing programming languages and their average annual salaries. The goal is to extract this information and store it in a structured format for further analysis.

## Features

- Extract programming language names from the HTML table
- Extract corresponding average annual salaries
- Store the collected data in a CSV file for easy access and analysis

## Dataset

The data comes from an HTML table hosted online by Skills Network. It contains multiple programming languages along with their reported average annual salaries.

## Purpose

The main purpose of this project is to practice web scraping using Python, understand how to parse HTML tables, and organize scraped data into a usable format such as CSV.
